# Projeto Responsividade

Este projeto foi desenvolvido com o auxílio e direcionamento da plataforma Rocketseat. O objetivo principal foi aprofundar conhecimentos em responsividade, aplicando boas práticas de código limpo, organizado e conceitos de CSS dinâmico.

## Funcionalidades

*   Desenvolvimento estruturado utilizando boas práticas de semântica em HTML e estilização avançada com CSS.
*   Uso estratégico de media queries e conceitos de design responsivo para adaptação em diferentes tamanhos de tela.
*   Estrutura de código limpa, modular e de fácil manutenção.

## Tecnologias Utilizadas

*   **Front-end:** HTML e CSS
